# 08 - 技术依赖

## Go

| 模块 | 用途 |
|------|------|
| `net/http` | HTTP API、SSE、静态文件和 CORS |
| `os/exec` | rclone rcd 与 mount 子进程 |
| `log/slog` | 日志 |
| `github.com/google/uuid` | 节点、边、job 标识 |
| `github.com/robfig/cron/v3` | 同步计划 |
| `github.com/wailsapp/wails/v3` | 桌面窗口。业务 API 不走 Wails binding |

下载校验、cron 解析和跨平台 mount 参数库在对应阶段选择，必须优先维护活跃、跨平台且不扩大安全边界的实现。

外部运行时是 rclone。支持系统 PATH、自定义路径和 Ourboros 下载的托管版本。

## 前端

| 包 | 用途 |
|----|------|
| `react` / `react-dom` | UI |
| `react-router` | 路由 |
| `zustand` | 状态 |
| `i18next` / `react-i18next` | 多语言 |
| `lucide-react` | 图标 |
| `@fontsource-variable/inter` | 字体 |
| `@base-ui/react` | shadcn 基础组件 |
| `react-resizable-panels` | 可调整面板 |

前端不引入 rclone RC SDK，所有通信通过 Ourboros typed API。

## 工具链

- Go：`gofmt`、`go test ./internal/... ./cmd/ourboros`。
- Web：`npm ci`、`npm run typecheck`（`tsc`）、`npm run lint`（oxlint，配置在 `.oxlintrc.json`）、`npm run build`；格式化用 `npm run format`（oxfmt，配置在 `.oxfmtrc.json`）。
- 桌面：`go build -o Ourboros ./cmd/desktop`。
- 依赖版本通过 lockfile 固定，发布使用干净环境重建。
