# 08 - 技术依赖

## Rust

| Crate | 用途 |
|-------|------|
| `axum` | HTTP |
| `tokio` | 异步运行时、子进程 |
| `reqwest` | 调用 rclone RC |
| `tower-http` | CORS、静态文件 |
| `clap` | CLI（含 env） |
| `tracing` | 日志 |
| `thiserror` | core 错误 |
| `anyhow` | binary 错误 |

外部依赖：**rclone** 必须安装在 PATH 中，或通过 `--rclone-bin` 指定。

## 前端

| 包 | 用途 |
|----|------|
| `react` / `react-dom` | UI |
| `react-router` | 路由 |
| `zustand` | 状态 |
| `i18next` / `react-i18next` | 多语言 |
| `lucide-react` | 图标 |
| `react-resizable-panels` | 三栏布局 |
