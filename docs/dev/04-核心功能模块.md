# 04 - 核心功能模块

## rclone 管理

- 启动 / 停止 / 查询状态
- 解析 rclone 二进制（PATH 或 `--rclone-bin`）
- 就绪探测（`core/version`）

## RC 代理

- `POST /api/rc/{command}` 转发到 rclone RC
- command 只允许 `[A-Za-z0-9/_-]`
- 透传 rclone 的 JSON 与 HTTP 状态码

## 浏览

- `config/listremotes`
- `operations/list`
- `operations/mkdir`
- `operations/deletefile` / `operations/purge`

## 传输

- 轮询 `core/stats` 展示当前 transferring 列表

## 后续

- remote 创建向导（`config/providers` + `config/create`）
- 复制 / 移动 / sync
- mount
- 限速（`core/bwlimit`）
