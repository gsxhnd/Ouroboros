# 04 - 核心功能模块

## 模块总览

| 模块 | 职责 | 首轮状态 |
|------|------|----------|
| rclone 管理 | 发现、下载、启动、attach、停止和版本管理 | 必须 |
| RC 适配层 | allowlist、超时、错误转换和敏感命令过滤 | 必须 |
| Workspace | 节点、连线、视口、校验和 JSON 持久化 | 必须 |
| Remote/File | remote 配置、目录浏览和基础文件操作 | 必须 |
| Sync | copy/move/sync、job、进度、取消和计划调度 | 必须 |
| Mount | 远程到本地的 mount 子进程生命周期 | 必须 |
| Settings | rclone 来源、配置路径、自动启动和 UI 偏好边界 | 必须 |
| 历史/多用户 | 任务历史、账号、权限和审计 | 后续 |

## rclone 管理

- 扫描并验证系统 PATH、自定义路径和托管版本。
- 选择优先级为用户指定路径 > 托管版本 > 系统 PATH。
- 托管版本支持查询、下载、校验、激活、删除和回滚。
- `RcloneSupervisor` 防止重复启动，检测异常退出并支持优雅停止。
- RC 只监听回环地址并使用临时凭据。

## RC 适配层

- 浏览器不直接连接 rclone RC。
- 常用操作由 typed API 映射到固定的 RC 命令和参数。
- 通用 `POST /api/rc/{command}` 只允许 allowlist 命令。
- command 只接受 `[A-Za-z0-9/_-]`，拒绝敏感配置导出命令。
- 统一超时、上游错误、未运行状态和响应转换。

## Workspace

- 创建、更新、删除 local/remote 节点。
- 创建、更新、删除有向 sync/mount 连线。
- 保存节点位置和画布视口。
- 校验节点引用、重复连线、路径、remote 名称和挂载方向。
- 修改工作区后使用版本号防止并发覆盖，写入采用临时文件 + rename。

## Remote 与文件

- `config/listremotes` 返回 remote 列表。
- 支持 remote 创建和编辑，但敏感字段不进入 workspace JSON。
- `operations/list` 即时读取目录，不建立文件索引。
- 支持 mkdir、copy、move、delete、purge，并区分可逆/破坏性操作。
- 文件 API 统一校验 `fs`、`remote`、相对路径和操作类型。

## 同步任务与计划

- 建线时确定 `copy`、`move` 或 `sync`；手动和计划执行使用同一配置。
- `sync` 可能删除目标多余文件，`move` 会改变源内容，均需明确确认。
- 每条同步线独立保存启用开关、预设频率或 cron、时区、下次运行和最近结果。
- 同一条边不可并发运行；支持取消、失败、部分失败、过期和重试。
- 任务进度通过首次快照 + SSE 发送，断线重连后重新同步。

## 挂载生命周期

- 只允许 remote 源 → local 目标。
- 启动 `rclone mount` 子进程并记录 starting/mounted/stopping/stopped/failed 状态。
- 防止同一边重复挂载，停止时清理子进程和残留状态。
- 捕获退出码、stderr 和平台不支持错误。
- 默认服务重启不自动恢复 mount，除非以后增加明确设置。

## 应用设置

- rclone 来源、配置文件路径、自动启动偏好和工作区文件位置。
- 设置与 workspace JSON 都带 schema 版本并支持迁移。
- CLI 参数只覆盖当前进程，不隐式修改已保存配置。
- UI 主题、语言、面板宽度等非敏感偏好留在浏览器 localStorage。
