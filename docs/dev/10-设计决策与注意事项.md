# 10 - 设计决策与注意事项

## 关键决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 产品 | rclone Web UI | 替换原素材库方向 |
| 桌面形态 | HTTP + 浏览器 | 本机与 NAS 同一套架构 |
| rclone 集成 | 托管 `rclone rcd` + 代理 RC | 不重新实现云存储协议 |
| RC 暴露 | 仅 127.0.0.1，由 Ourboros 代理 | 避免把无鉴权 RC 开到网上 |
| 数据 | 不自建业务库 | rclone.conf 已是真实数据源 |
| UI | React + shadcn | 沿用现有前端栈 |

## 注意事项

1. **安全**：当前 `--rc-no-auth` 仅因 RC 绑在回环地址。若 `--host 0.0.0.0`，必须先给 Ourboros 加鉴权，且不要把 rclone RC 端口映射出去。
2. **rclone 必须存在**：找不到二进制时服务仍会起来，UI 显示未连接，可在设置里重试。
3. **删除**：目录走 `purge`，不可恢复。
4. **密钥**：不要把 `config/dump` 原样展示给前端，里面有 token。
5. **路径**：rclone `fs` + `remote` 两段式路径，本机入口的 `fs` 是 HOME 绝对路径。
