# 06 - 前端设计

## 技术栈

| 库 | 用途 |
|----|------|
| React 19 | UI 与交互 |
| Vite 8 | 开发服务器和构建 |
| shadcn/ui + Tailwind CSS 4 | 组件与样式 |
| Zustand | 工作区、任务和 UI 状态 |
| TanStack Router | 路由 |
| i18next / react-i18next | 中/英多语言 |
| lucide-react | 图标 |
| `@xyflow/react`（默认候选） | 节点画布 |

## 路由

| 路径 | 页面职责 |
|------|----------|
| `/` | Canvas 工作区首页，节点、连线、inspector 和活动面板 |
| `/files` | Remotes、本地目录、文件表和详情 |
| `/jobs` | 同步/复制/移动任务和历史状态 |
| `/settings` | rclone 安装、路径、连接、主题和语言 |

首页是首屏重点；其他页面为画布操作提供深入管理，不复制画布的节点/边编辑逻辑。

## Canvas 工作区

### 页面构成

- `CanvasWorkspace`：画布引擎适配层、视口、节点和边渲染。
- `CanvasToolbar`：添加节点、保存、撤销/重做、适配视图和运行入口。
- `NodePalette`：本地目录、已有 remote 和 remote 配置入口。
- `NodeInspector`：节点名称、路径、remote 引用、校验和删除。
- `EdgeInspector`：同步/挂载类型、方向、操作策略、计划、挂载参数和危险操作。
- `ActivityPanel`：job、挂载状态、进度、失败详情、取消和重试。

### 节点交互

- 添加本地节点时输入或选择绝对目录。
- 添加 remote 节点时选择已有 remote 并填写相对路径。
- remote 节点可打开受控新建/编辑 remote 流程，凭据不进入前端持久化状态。
- 节点显示类型、label、路径摘要、在线/错误状态和可用操作。
- 拖拽结束后批量保存位置，不在每一帧调用 API。

### 连线交互

1. 从源节点输出端拖到目标节点输入端。
2. 创建连接面板选择 `sync` 或 `mount`。
3. sync 线配置 `copy`、`move`、`sync` 以及每线独立计划。
4. mount 线只允许 remote → local，并配置挂载目录和支持的选项。
5. 选中边显示运行、暂停、挂载、卸载、删除和最近结果。
6. 删除节点时先列出会被删除的边；删除边时确认计划或 mount 状态影响。

## 状态边界

### 服务端状态

- rclone 会话、remote 列表、文件列表。
- workspace 节点、边、视口和计划。
- jobs、SSE 进度、mount 进程状态和错误。
- rclone 版本、下载状态和应用设置。

### Zustand

- 当前 workspace 快照和 revision。
- 选中节点/边、视口、面板展开状态。
- 拖拽/连线中的临时状态、乐观更新和待保存标记。
- 当前活动任务的服务端快照。

### localStorage

- 主题、语言、面板宽度和其他非敏感 UI 偏好。
- 不保存 RC URL、RC 凭据、remote token、完整 workspace 或任务权威状态。

## 数据请求

- 统一封装 `services/http.ts`，请求和响应使用 TypeScript 类型。
- `/api/workspace` 首次加载后，节点/边写操作使用资源接口并更新 revision。
- job、下载和 mount 使用首次快照 + SSE。
- 短暂断线指数退避；恢复后重新拉取快照而不是只依赖事件补齐。
- 所有页面显示 loading、empty、error、offline 和 rclone 未就绪状态。

## 交互与性能基线

- 节点和边组件独立 memo 化，避免视口更新导致整图重渲染。
- 高频拖拽坐标使用 ref/局部状态，结束后提交 store 和服务端。
- 任务/文件长列表使用虚拟化或 `content-visibility`。
- 非首屏路由和重型面板按需加载。
- 删除、purge、move、sync 等危险动作使用 Dialog/AlertDialog 明确展示源、目标和影响。
- 成功/失败使用统一 toast，详细错误可复制。
- 画布及节点必须支持键盘删除、选中态、清晰焦点和基础无障碍标签。

## 画布适配接口

业务层不直接依赖某个画布库，定义最小 `CanvasAdapter` 边界：

- 输入：`StorageNode[]`、`ConnectionEdge[]`、`Viewport`。
- 输出：节点拖拽、边创建/删除、选择、视口变化和键盘操作事件。
- 能力：序列化/反序列化、自定义节点/边渲染、适配视图。

默认候选为 React Flow；是否引入依赖在 [08-技术依赖](./08-技术依赖.md) 的 spike 后确定。
