# 06 - 前端设计

## 技术栈

| 库 | 用途 |
|----|------|
| React 19 | UI 与交互 |
| Vite 8 | 开发服务器和构建 |
| react-router 8 | 路由（页面视图与设置子分区） |
| shadcn/ui + Tailwind CSS 4 | 组件与样式 |

| i18next / react-i18next | 中/英多语言 |
| lucide-react | 图标 |

## 视图与路由

| 路由 | 职责 |
|------|------|
| `/` | 重定向到 `/tasks` |
| `/tasks`（`features/sync/sync-page.tsx`） | 同步任务首页：任务列表、运行进度、最近结果 |
| `/files`（`features/files/files-page.tsx`） | Remotes、本地目录浏览与文件操作 |
| `/storages`（`features/storages/storages-page.tsx`） | 本地目录和 remote 的创建、编辑与删除 |
| `/overview`（`features/overview/overview-page.tsx`） | rclone 状态、二进制选择与版本下载 |
| `/settings`（`features/settings/settings-page.tsx`） | 设置布局，内含三个子路由：`connection` / `shortcuts` / `runtime` |
| `/api`（`features/api-playground/api-playground-page.tsx`） | API Playground：端点列表 + 请求 + 响应 |

应用使用 react-router：`app/app.tsx` 定义路由，`AppShell` 是布局路由（顶栏 + 侧边栏 + `<Outlet />`）。侧边栏按「工作区 / 系统」分组排序，与命令面板共用 `app/nav.ts` 导航注册表（分组、路径、语言键、图标只定义一次）。托盘视图（`TrayPanel`）是独立入口，不进入路由。

## 同步任务页

### 页面构成

- 页头：标题、rclone 离线提示、"新建同步"入口。
- 运行中任务：所有非终态 job 的进度、速度、传输数、错误数和停止按钮。
- 任务列表：名称、操作徽标、限速/限额徽标、源→目标、计划、下次运行、最近结果和启停开关。
- 任务卡片操作：立即运行、停止、重新初始化（bisync）、编辑、删除。

### 新建 / 编辑任务

- 名称；源与目标端点编辑器：本地绝对目录或 remote + 可选子路径。
- 方向：单向（操作选择镜像同步 / 复制 / 移动）或双向（bisync）。
- 危险操作提示：镜像同步会删除目标多余文件，移动会删除源文件，双向会双向传播删除。
- 限速与单次大小上限输入框，说明格式与全局生效语义。
- 计划：手动 / 每小时 / 每天 / 每周 / cron + 表达式；默认使用本地时区。
- 启用开关。

### 危险操作确认

- 运行破坏性任务（move / sync / bisync）前弹出确认对话框，展示源、目标与影响文本。
- 双向同步首次运行（无成功记录）确认时自动附带 resync；正常双向运行的确认展示双向删除警告。
- 双向任务提供独立的"重新初始化 (resync)"操作，用于配置变更或出错恢复。
- 删除任务需要输入任务名称确认。

## 存储页

- 本地存储：新建（名称 + 绝对路径）、删除；显示被同步任务引用的数量，被引用时禁止删除（服务端 409 `node_in_use`）。
- 远程存储：通过恢复的 `RemoteFormDialog` 选择存储类型（常用类型置顶 + 搜索 + 高级选项）创建/编辑 remote；删除 remote 需输入名称确认（会连带 rclone 凭据），被同步任务引用时服务端 409 `remote_in_use`。
- rclone 未运行时远程存储区展示提示，本地存储不受影响。

## 状态边界

### 服务端状态

- rclone 会话、remote 列表、文件列表。
- 同步任务、任务 revision、job 快照与 SSE 进度、mount 进程状态和错误。
- rclone 版本、下载状态和应用设置。

### Zustand

- `features/sync/sync-store.ts`：任务列表、revision、job 快照；写操作按 revision 串行提交，冲突或失败回拉服务端快照。
- `stores/rclone-store.ts`（唯一保留在全局 `stores/` 的 store）：rclone 状态轮询与启停。
- SSE 订阅（`/api/sync/jobs/events`）在页面挂载时建立，重连后重新拉取快照。

### localStorage

- 主题、语言和其他非敏感 UI 偏好。
- 不保存 RC URL、RC 凭据、remote token、workspace 文档或任务权威状态。

## 数据请求

- 统一封装 `services/http.ts`，请求和响应使用 TypeScript 类型。
- 任务读写在 `/api/sync/tasks` 上进行，运行使用 `/api/sync/tasks/{id}/run`。
- job 使用首次快照 + SSE。
- 短暂断线指数退避；恢复后重新拉取快照而不是只依赖事件补齐。
- 所有页面显示 loading、empty、error、offline 和 rclone 未就绪状态。

## 交互与性能基线

- 删除、move、sync、bisync 等危险动作使用 Dialog 明确展示源、目标和影响。
- 成功/失败使用统一 toast，详细错误可复制。
- 任务/文件长列表使用虚拟化或 `content-visibility`。
