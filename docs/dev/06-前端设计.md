# 06 - 前端设计

## 技术栈

| 库 | 用途 |
|----|------|
| React 19 | UI |
| Vite | 构建 |
| shadcn/ui + Tailwind CSS 4 | 组件与样式 |
| zustand | 状态 |
| react-router | 路由 |
| i18next | 中/英 |

## 路由

| 路径 | 页面 |
|------|------|
| `/` | 文件浏览 |
| `/jobs` | 传输任务 |
| `/settings` | 主题、语言、rclone 连接 |

布局：左侧 remotes，中间文件表，右侧选中项详情。

## 数据请求

- Ourboros API：`services/http.ts`
- rclone 命令：`http.rc("operations/list", { fs, remote })`
- 传输进度：布局级每 2 秒轮询 `core/stats`
- 不直连 rclone RC 端口
