# 03 - rclone 连接模型

## 托管模式（默认）

`ourboros server` 启动后：

1. 在 `127.0.0.1` 上选一个空闲端口
2. 执行 `rclone rcd --rc-addr 127.0.0.1:<port> --rc-no-auth`
3. 轮询 `core/version` 直到就绪
4. 通过 `/api/rc/{command}` 把前端请求转给 RC

RC 不对局域网暴露。鉴权由后续 Ourboros 自己的 HTTP 层承担（当前开发默认仅绑 `127.0.0.1`）。

可用 `--rclone-bin` / `--rclone-config` 指定二进制和配置文件。

## Attach 模式

`--rclone-url http://127.0.0.1:5572`（或 `RCLONE_RC_URL`）时不拉起子进程，只连接已有 RC。

## 本机目录

除 `config/listremotes` 返回的 remote 外，UI 会加入一个指向用户 HOME 的本机入口，底层仍走 `operations/list`。

## 不持久化业务库

Ourboros 不再使用 SQLite / SeaORM。remote、凭证、传输状态都以 rclone 为准。
