# 09 - 开发阶段规划

本项目按全新未开发项目规划。文档中的任务在实现前均视为未完成；只有通过对应测试和验收后才勾选。画布方向已移除，规划已按同步任务页调整。

## Phase 0：产品契约

- [x] 冻结节点、同步任务、计划、job、mount 和错误模型。
- [x] 定义 TypeScript/Go 类型映射、revision 和 schema 版本。
- [x] 移除画布方向，确定以同步任务页为首页。

## Phase 1：基础工程与安全控制面

- [ ] 建立 Go module、HTTP 路由、静态 Web 托管和统一错误模型。
- [ ] 实现 rclone 托管启动、attach、停止、ready 探测和 supervisor 状态机。
- [ ] 使用 RC 临时凭据，隐藏 RC URL/凭据，限制 RC allowlist。
- [ ] 配置生产同源和开发 origin 白名单，移除任意 CORS。
- [ ] 建立日志脱敏、超时和异常退出处理。

## Phase 2：rclone 来源、设置与存储基础

- [ ] 扫描系统 PATH、自定义路径和托管版本。
- [ ] 实现版本验证、官方下载、SHA-256/签名校验、激活、删除和回滚。
- [ ] 实现版本化设置 JSON、迁移、原子写入和损坏文件保护。
- [ ] 实现 remote 列表、创建/编辑表单和本地路径校验。
- [ ] 完成 `fs` + `remote` 两段式路径模型和统一校验器。

## Phase 3：同步任务后端

- [ ] 实现 workspace JSON、schema 版本、revision 和并发保存保护。
- [ ] 实现同步任务 API：创建/更新/删除时自动复用端点节点并清理孤儿节点。
- [ ] 实现单向 `copy`/`move`/`sync` 与双向 `bisync`（含首次 resync 约束）。
- [ ] 实现限速（进程全局 `core/bwlimit`）与单次大小上限（`_config` MaxTransfer + HARD）。
- [ ] 覆盖 rclone 缺失时的读取、编辑和依赖操作错误状态。

## Phase 4：React 同步任务首页

- [ ] 配置 Vite `1420` 和 `/api` 代理。
- [ ] 初始化 typed API client、Zustand、i18next。
- [ ] 实现同步任务页：任务列表、新建/编辑表单、运行/停止、进度与最近结果。
- [ ] 实现 loading、empty、error、offline、未就绪和危险操作确认。
- [ ] 实现 job SSE 订阅、断线恢复与刷新恢复。

## Phase 5：文件浏览

- [ ] 实现目录浏览、mkdir、copy、move、delete、purge。
- [ ] 实现单文件流式下载（RC 文件服务器代理）与重命名。
- [ ] 文件浏览以浮层形式从应用外壳打开。

## Phase 6：真实挂载

- [ ] 限制 mount 为 remote 源 → local 目标。
- [ ] 实现 `rclone mount` 子进程启动、监管、停止和退出清理。
- [ ] 实现 mounted/failed/stopped 状态、退出码和诊断信息。
- [ ] 实现重复操作保护、平台能力检测和 UI 状态同步。
- [ ] 默认不自动恢复挂载，补充后续自动恢复的权限与清理设计。

## Phase 7：验证与发布

- [ ] Go 单元、集成和 HTTP API 测试。
- [ ] React store、API client 和错误状态测试。
- [ ] 执行 `fmt/test` 与 `typecheck/lint/build`。
- [ ] 端到端覆盖无 rclone、系统/自定义/托管版本、attach、异常退出、同步、计划和 mount。
- [ ] 修正 release workflow，构建并发布 Go 服务二进制与 `web/dist`。
