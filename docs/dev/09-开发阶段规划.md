# 09 - 开发阶段规划

本项目按全新未开发项目规划。文档中的任务在实现前均视为未完成；只有通过对应测试和验收后才勾选。

## Phase 0：产品契约与画布技术 spike

- [ ] 冻结节点、边、计划、job、mount 和错误模型。
- [ ] 定义 TypeScript/Rust 类型映射、revision 和 schema 版本。
- [ ] 建立 `CanvasAdapter` mock，实现节点拖拽、连线、删除和序列化基准。
- [ ] 对 React Flow、LiteGraph.js、DOM + SVG 做同一交互和性能 spike。
- [ ] 记录最终画布引擎选择和依赖许可结论。

## Phase 1：基础工程与安全控制面

- [ ] 建立 Rust workspace、Axum 路由、静态 Web 托管和统一错误模型。
- [ ] 实现 rclone 托管启动、attach、停止、ready 探测和 supervisor 状态机。
- [ ] 使用 RC 临时凭据，隐藏 RC URL/凭据，限制 RC allowlist。
- [ ] 配置生产同源和开发 origin 白名单，移除任意 CORS。
- [ ] 建立日志脱敏、超时和异常退出处理。

## Phase 2：rclone 来源、设置与存储基础

- [ ] 扫描系统 PATH、自定义路径和托管版本。
- [ ] 实现版本验证、官方下载、SHA-256/签名校验、激活、删除和回滚。
- [ ] 实现版本化设置 JSON、迁移、原子写入和损坏文件保护。
- [ ] 实现 remote 列表、创建/编辑表单和本地路径校验。
- [ ] 完成 `fs` + `remote` 两段式路径模型和统一校验器。

## Phase 3：Workspace 后端

- [ ] 实现 workspace JSON、schema 版本、revision 和并发保存保护。
- [ ] 实现 local/remote 节点 CRUD、位置和 viewport 保存。
- [ ] 实现有向 sync/mount 边 CRUD、重复边和非法方向校验。
- [ ] 实现 workspace typed API 与错误码。
- [ ] 覆盖 rclone 缺失时的读取、编辑和依赖操作错误状态。

## Phase 4：React Canvas 首页

- [ ] 配置 Vite `1420` 和 `/api` 代理。
- [ ] 初始化 TanStack Router、typed API client、Zustand、i18next。
- [ ] 接入 Phase 0 选定的画布引擎。
- [ ] 实现首页 Canvas、工具栏、节点面板、边面板和活动面板。
- [ ] 实现 loading、empty、error、offline、未就绪和危险操作确认。
- [ ] 实现节点/边 memo、拖拽批量保存和刷新恢复。

## Phase 5：文件与同步任务

- [ ] 实现目录浏览、mkdir、copy、move、delete、purge。
- [ ] 实现 `copy`、`move`、`sync` 的手动运行和服务端危险操作校验。
- [ ] 实现 job 查询、进度 SSE、取消、重试、部分失败和过期状态。
- [ ] 实现每条同步边的预设/cron、时区、启停、下次运行和最近结果。
- [ ] 防止同一边并发运行，断线恢复后以服务端快照为准。

## Phase 6：真实挂载

- [ ] 限制 mount 为 remote 源 → local 目标。
- [ ] 实现 `rclone mount` 子进程启动、监管、停止和退出清理。
- [ ] 实现 mounted/failed/stopped 状态、退出码和诊断信息。
- [ ] 实现重复操作保护、平台能力检测和 UI 状态同步。
- [ ] 默认不自动恢复挂载，补充后续自动恢复的权限与清理设计。

## Phase 7：验证与发布

- [ ] Rust 单元、集成和 HTTP API 测试。
- [ ] React store、画布交互、API client 和错误状态测试。
- [ ] 执行 `fmt/clippy/test` 与 `typecheck/lint/build`。
- [ ] 端到端覆盖无 rclone、系统/自定义/托管版本、attach、异常退出、同步、计划和 mount。
- [ ] 修正 release workflow，构建并发布 Rust 二进制与 `web/dist`。

## 后续阶段

- [ ] 多工作区、导入导出和远程 Ourboros 实例节点。
- [ ] 任务历史、审计、多用户和 HTTP 鉴权。
- [ ] Docker、带宽限制和 Tauri 桌面壳。
