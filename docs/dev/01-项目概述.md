# 01 - 项目概述

## 简介

Ourboros 是一个面向 rclone 的 Web UI。它负责启动或连接 rclone 的 Remote Control（RC）接口，并提供远程浏览、目录操作和传输进度界面。适合本机使用，也适合跑在 NAS / 服务器上后用浏览器访问。

## 核心目标

- 用现代 Web UI 操作 rclone，而不是只靠命令行
- 默认由 Ourboros 托管 `rclone rcd`，RC 仅监听本机回环地址
- 也可以连接到已经在跑的 rclone RC（例如 NAS 上的现有进程）
- 通过 `ourboros server` 独立部署，UI 用浏览器打开
- 不自建文件索引数据库，remote 与配置以 rclone 为准

## 核心功能（当前）

- 自动发现并启动 rclone RC，或 attach 到已有 RC
- 列出 rclone remotes，并浏览本机目录
- 目录列表、进入、上级、筛选
- 新建文件夹、删除文件/目录
- 查看当前传输任务（`core/stats`）
- 主题 / 语言设置
