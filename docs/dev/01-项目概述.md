# 01 - 项目概述

## 产品定位

Ourboros 是一个以画布为首页的本地优先 rclone Web UI。用户通过浏览器在一个类似 ComfyUI 的工作区中放置本地目录和 rclone remote 节点，再用有向连线配置同步或挂载关系。

Ourboros 负责控制面、工作区配置、任务调度和进程监管；rclone 负责 remote、凭证、文件操作和传输执行。项目不重新实现云存储协议，也不建立文件索引数据库。

## 核心目标

- 以单一默认画布作为首页，支持缩放、平移、节点拖拽、选中和连线。
- 支持两类存储节点：本机目录、`rclone remote/path`。
- 通过有向连线表达源节点到目标节点的配对关系。
- 每条连线只能是同步或挂载之一；同步策略在建线时确定并持久化。
- 支持手动同步、每条同步线独立的预设/cron 计划，以及任务进度和取消。
- 支持远程源到本地目录的真实挂载、卸载和异常状态展示。
- 浏览器只访问 Ourboros typed API，不直接访问 rclone RC。
- rclone 缺失、未就绪或异常退出时，服务仍可启动并提供可诊断的 Web UI。

## 首轮范围

### 包含

- rclone 托管启动和 attach 模式。
- 系统 PATH、自定义路径和 Ourboros 托管版本的发现与选择。
- 工作区节点、连线、视口和同步计划的服务端 JSON 持久化。
- 本地节点、已有 remote 节点和 remote 配置入口。
- `copy`、`move`、`sync` 三种同步操作。
- 同步任务、SSE 进度、取消、重试和最近结果。
- 远程源到本地目录的 rclone mount 生命周期。
- 文件浏览、目录操作、设置和发布包。

### 不包含

- 多工作区导航。
- 远程 Ourboros 实例节点。
- 前端保存 remote 凭据或完整 rclone 配置。
- 文件索引、素材库、SeaORM/SQLite 业务数据库。
- Tauri、桌面托盘和系统级自动启动。
- 在未实现 HTTP 鉴权前的局域网/公网部署。

## 运行形态

```text
ourboros server
    ├── Axum HTTP API
    ├── 静态托管 web/dist
    ├── 工作区/设置 JSON
    └── rclone supervisor
            └── rclone rcd / rclone mount
```

默认监听 `127.0.0.1:8080`，开发环境使用 Vite `127.0.0.1:1420` 并代理 `/api`。不引入 Tauri/WebView；未来桌面端只作为同一 HTTP 控制面的薄封装。
