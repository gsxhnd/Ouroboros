# 02 - 架构设计

## 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                     Frontend (React)                      │
│        shadcn/ui + zustand + i18next + react-router       │
│              只访问 Ourboros HTTP，不直连 rclone RC        │
└────────────────────────┬────────────────────────────────┘
                         │ HTTP REST / 静态资源
┌────────────────────────▼────────────────────────────────┐
│                    ourboros (Axum)                        │
│   CLI: server                                             │
│   托管 Web UI + 代理 rclone RC + 进程管理                 │
└────────────────────────┬────────────────────────────────┘
                         │ POST /<command>  JSON
┌────────────────────────▼────────────────────────────────┐
│                      rclone rcd                           │
│   默认 127.0.0.1:<随机端口> --rc-no-auth                   │
│   或 attach 到 --rclone-url                               │
└─────────────────────────────────────────────────────────┘
```

## 单一二进制 + 子命令

| 子命令 | 用途 |
|--------|------|
| `ourboros server` | HTTP 服务 + rclone 管理 |
| `ourboros version` | 打印版本 |

用户通过系统浏览器访问 Web UI，不使用 Tauri / WebView。

## Web UI 托管策略

前端构建产物 `web/dist` **不 embed 进二进制**：

1. CLI `--web-dir`
2. 环境变量 `OURBOROS_WEB_DIR`
3. 可执行文件旁 `web/` 等自动探测

找不到 `index.html` 时进入 API-only 模式。

开发模式使用 Vite（`:1420`）+ proxy 到后端。

## Monorepo

```
Ourboros/
├── crates/
│   ├── ourboros-core/     # rclone 进程管理与 RC 客户端
│   └── ourboros/          # CLI + Axum
├── web/                   # React UI
└── docs/dev/
```
